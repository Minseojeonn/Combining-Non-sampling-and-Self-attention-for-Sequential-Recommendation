# PyTorch Implementation of "Combining Non-sampling and Self-attention for Sequential Recommendation"

This is an **unofficial** PyTorch implementation of the NSSR model, based on the [SASRec.pytorch](https://github.com/pminkyu/SASRec.pytorch) repository.

## 📌 References
* **Original Paper:** [Combining Non-sampling and Self-attention for Sequential Recommendation](https://www.sciencedirect.com/science/article/pii/S0306457321002892)
* **Original TensorFlow Implementation:** [conquerSelf/NSSR](https://github.com/conquerSelf/NSSR)
* **Base Architecture:** [SASRec.pytorch](https://github.com/pminkyu/SASRec.pytorch)
